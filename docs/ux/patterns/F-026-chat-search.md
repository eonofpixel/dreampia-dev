# F-026: 채팅 검색 팔레트 + 빠른 점프

> **한 줄 요약**: Ctrl+K 로 모든 채팅 검색. Ctrl+1~9 로 사이드바 1~9번째 채팅 즉시.

---

## Ctrl+K — 검색 팔레트

```
┌────────────────────────────────────────────┐
│ 🔍 [검색어 입력...]                        │
├────────────────────────────────────────────┤
│ 채팅:                                      │
│   "서버 열고 미리보기 확인" - 어제          │
│   "테스트 통과시키기" - 2시간 전           │
│   "리팩토링 진행" - 3일 전                 │
│                                            │
│ 메시지:                                    │
│   "...localhost:3000..." in "서버 열고..." │
│   "...assertion error..." in "테스트..."   │
│                                            │
│ 파일:                                      │
│   src/foo.ts                               │
│   tests/foo.test.ts                        │
└────────────────────────────────────────────┘
```

## 검색 범위

```
1. 채팅 제목 (Ctrl+K → 기본)
2. 채팅 메시지 본문 (FTS5)
3. 파일명 (workspace 안)
4. 명령 (/<cmd>)
```

## Ctrl+1~9 — 빠른 점프

```
사이드바 1~9번째 채팅으로 즉시 이동.

[사이드바]
  1. 서버 열고 미리보기 확인     ← Ctrl+1
  2. 테스트 통과시키기           ← Ctrl+2
  3. 리팩토링 진행               ← Ctrl+3
  ...
  9. 9번째                       ← Ctrl+9
```

## 핵심 인사이트

```
사용자가 자주 쓰는 채팅이 1~9 위에 위치
→ Ctrl+숫자 = 손 안 떼고 즉시 점프
→ 마우스보다 빠름
```

## 핀 (pinned) 채팅 우선

```
사이드바 정렬:
  1. Pinned 채팅들 (사용자 명시)
  2. Recent 채팅들 (updated_at DESC)

→ Ctrl+1~9 도 이 순서로
```
