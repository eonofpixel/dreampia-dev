# F-014: 전체화면 토글 ⛶

> **한 줄 요약**: 미리보기를 전체 화면으로. 사이드바 슬림 + floating chat overlay.

---

## 동작

```
3-패널 모드 → ⛶ 클릭 → 전체화면 모드

전체화면:
  - 미리보기가 화면 거의 전체 차지
  - 사이드바 슬림 (텍스트 X, 아이콘만)
  - 채팅 패널 사라짐 (대신 floating overlay)
```

## UI 변화

```
[3-패널 모드]
┌──────────┬──────────────────┬────────────────────────────────────┐
│ Sidebar  │   채팅            │   미리보기                          │
└──────────┴──────────────────┴────────────────────────────────────┘

[전체화면 모드]
┌──┬─────────────────────────────────────────────────────────────────┐
│≡ │                                                                 │
│  │                                                                 │
│  │              미리보기 (전체)                                     │
│  │                                                                 │
│  │                              ┌──────────────────────────────┐  │
│  │                              │ 최근 메시지            ⌄      │  │
│  │                              │ + ⚠ <입력>...   5.5 매우 높음 │  │
│  │                              └──────────────────────────────┘  │
└──┴─────────────────────────────────────────────────────────────────┘
                                  ↑ Floating overlay
```

## 단축키

```
F11 또는 ⛶ 클릭 → toggle
Esc → 전체화면 해제
```
