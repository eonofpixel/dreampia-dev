# Empty App States

> **한 줄 요약**: 빈 상태 모음. 항상 다음 행동 권유.

---

## 종류

### 1. App 처음 (no workspace)

```
[메인 화면]
사이드바: 거의 비움
중앙: Welcome + workspace 선택
미리보기: 비움

[중앙 채팅 영역]
┌──────────────────────────────────────────┐
│              👋 안녕하세요                │
│                                          │
│   작업할 프로젝트를 선택해주세요          │
│                                          │
│   [📁 폴더 찾아보기]                     │
│                                          │
│   최근 사용:                             │
│   📁 ~/projects/foo                      │
│   📁 ~/projects/bar                      │
└──────────────────────────────────────────┘
```

### 2. Workspace 있음, 채팅 없음

```
[채팅 영역]
┌──────────────────────────────────────────┐
│              👋                          │
│                                          │
│   pyeongtaek-portal 작업 시작            │
│                                          │
│   추천 prompts (4-6개)                   │
│                                          │
│   또는 직접 입력...                      │
└──────────────────────────────────────────┘

[사이드바]
채팅
  아직 채팅이 없어요.
  [+ 새 채팅]
```

### 3. 채팅 활성, 메시지 없음

```
[채팅 영역]
빈 메시지 area

[입력창]
[+ ⊕ 메시지 입력...]
```

→ 메시지 area 자체는 비움 (placeholder X). 추천은 별도 영역.

### 4. AI 도구 / 플러그인 없음

```
[설정 → 플러그인]
┌──────────────────────────────────────────┐
│              📭                          │
│                                          │
│   설치된 플러그인이 없어요               │
│                                          │
│   AI 의 능력을 확장하세요:                │
│   - 브라우저 자동화                      │
│   - 데이터 분석                          │
│   - 외부 API 통합                        │
│                                          │
│   [마켓 보기] [내 플러그인 만들기]        │
└──────────────────────────────────────────┘
```

### 5. MCP 서버 없음

```
[설정 → MCP 서버]
┌──────────────────────────────────────────┐
│              🔌                          │
│                                          │
│   MCP 서버가 없어요                      │
│                                          │
│   외부 도구를 연결해서 AI 기능 확장:      │
│   - Filesystem MCP                       │
│   - Database MCP                         │
│   - Sentry MCP                           │
│                                          │
│   [+ MCP 서버 추가] [추천 보기]          │
└──────────────────────────────────────────┘
```

### 6. 자동화 없음

```
[설정 → 자동화]
┌──────────────────────────────────────────┐
│              🤖                          │
│                                          │
│   아직 자동화가 없어요                   │
│                                          │
│   매일 자동으로 실행되는 작업 만들기:    │
│   - 매일 아침 코드 리뷰                  │
│   - PR 작성 시 자동 테스트                │
│   - 매주 의존성 업데이트                 │
│                                          │
│   [+ 새 자동화]                          │
└──────────────────────────────────────────┘
```

### 7. 검색 결과 없음

```
[Ctrl+K 검색 후]
┌──────────────────────────────────────────┐
│ 🔍 [Codex 자동화]                        │
├──────────────────────────────────────────┤
│              검색 결과 없음              │
│                                          │
│   "Codex 자동화" 와 일치하는 항목 없음   │
│                                          │
│   [검색어 변경] [전체 보기]              │
└──────────────────────────────────────────┘
```

### 8. 보관함 비어있음

```
[설정 → 보관된 채팅]
┌──────────────────────────────────────────┐
│              📂                          │
│                                          │
│   보관된 채팅이 없어요                   │
│                                          │
│   채팅을 보관하면 사이드바에서 숨김.     │
│   언제든 복원 가능.                      │
└──────────────────────────────────────────┘
```

## 패턴 통합

각 빈 상태:
```
1. 큰 아이콘 / emoji (감정 호소)
2. 명확한 제목 (한 문장)
3. 짧은 설명 (왜 비어있는지)
4. 행동 권유 버튼 (다음 단계)
```

상세: [../design/states/empty.md](../design/states/empty.md).

---

## "왜 비어있는지" 인지 도움

```
✓ 좋음: "아직 채팅이 없어요 / 추천부터 시작해보세요"
✗ 나쁨: "데이터 없음" (왜 ?)

✓ 사용자 다음 행동 명확히
```

---

## 첫 사용자 vs 복귀

```
첫 사용자:    Welcome / 설명 풍부
   "Dreampia 에서 무엇을 할 수 있는지..."

복귀 사용자:  바로 actionable
   "[+ 새 자동화]"
```

→ Onboarding 완료 여부로 분기.

---

## 일러스트레이션 (Phase 2)

```
Emoji / SVG illustration → 더 풍부한 시각:
  📭 → 🎨 빈 우편함 일러스트
  🔌 → 🎨 케이블 끊긴 일러스트
  🤖 → 🎨 잠자는 로봇

→ Brand 친밀감 향상.
```
