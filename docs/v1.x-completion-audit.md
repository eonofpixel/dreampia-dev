## 잔존 부채 (v2.0 phase A 후보)

본 audit 시점에서 v2.0 phase A 로 청산 권고:

### HIGH
- **DREAMPIA_VCR_MODE production runtime 강제 부재** — `vcr.ts:116`, `vcrLoader.ts:14`. CI replay 외 production binary 에서 mode unset = no-op.
- **L1 respond audit log 누락** — permission `respond` (grant 결정) 측은 `AuditLogStore` 와 미연결. Queue 의 tool_use 측만 cover.
- **drive16-4 timeout option 부재** — `CliProviderOptions` (line 39-60) 에 `timeout_ms` 없음. 외부 abort 만 가능.
- **F3/H2 PermissionRequest discriminator 부재** — `src/types/permission.ts` discriminator 패턴 미적용. type narrowing 회귀 risk.
- **F4 utility_process plugin 격리 미채택** — `PluginManager.ts:7-22` D1 (trust-on-install) 만 채택. utility_process grep 0 hit. untrusted plugin RCE 가능.

### MEDIUM
- `MetadataExtra.{plan.active, permission.default_level}` legacy optional — v1.8.4 안전 우선 (즉시 제거 X), 후속 정리 필요.
- v1.4.x / v1.8.x cross-track slot 명명 — `release-checklist.md` 정식화 미완 (CHANGELOG line 17-20 약속).
- drive18 axe DISABLE_RULES = [] 는 light mode 만 cover (dark mode toggle 미보장 추정).
- `down_*.sql` 5개의 production runtime tool 부재 (CLI/UI 없음).

### LOW
- preload bridge legacy export — `app:delete-legacy-workspace` (v1.4.11 backfill 후 dead code 가능).
- `AuditEventName` enum string union fallback — type safety 약함.
- e2e regression 부재 영역: PreviewPanel annotation visual diff, MCP plugin manifest 거부 case, automation cron timezone.
