# Round 4: MCP 편집 폼 / 모양 설정

│                                                      │
│  인자                                                │

### 발견된 omx_* 서버

```
사전 설치된 4개 (oh-my-codex):
  - omx_code_intel  (oh-my-codex/dist/mcp/code-intel-server)
  - omx_memory
  - omx_state
  - omx_trace
```

### 핵심 인사이트

```
1. "환경 변수 패스스루" = 시스템 env 이름만 (값 X)
   → 보안 패턴: 비밀 노출 X 하면서 환경 정보 전달
   
2. "MCP 서버 유형 변경 시 설치 제거 후 재설치"
   → STDIO ↔ HTTP 변경 시 별도 처리 필요
   
3. 작업 디렉토리 기본 ~/code
```

### 핵심 인사이트

```
단순 다크/라이트 토글 X. 각 테마 별로 8+ 항목 fine-tuning.
  - Live preview (좌우 코드 비교)
  - 테마 import/export (가져오기/테마 복사)
  - 프리셋 (Codex 외 다른 프리셋 추정)
  - 글꼴 커스터마이즈 (UI / 코드 분리)
  - "반투명 사이드바" 같은 미세 옵션
```
